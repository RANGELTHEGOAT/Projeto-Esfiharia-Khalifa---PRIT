# Esfiharia Khalifa

Site institucional e cardápio digital da Esfiharia Khalifa, feito com HTML e CSS.

## Estrutura

Este repositório representa o módulo **WEB (front-end)** do projeto. O site é estático e não possui back-end, aplicativo móvel ou APIs.

- `index.html`: página inicial
- `sobre.html`: apresentação da esfiharia
- `salgados.html`, `doces.html`, `bebidas.html` e `combos.html`: cardápio
- `promocoes.html`: ofertas
- `localizacao.html`: endereço e contato
- `pedidos.html`: informações para pedidos
- `styles.css`: estilos compartilhados
- `imagens/`: organização e créditos das imagens

## Como abrir localmente

Abra o arquivo `index.html` em um navegador. As fotos hospedadas externamente precisam de conexão com a internet.

## Publicar com GitHub Pages

1. Crie um repositório no GitHub e envie o conteúdo desta pasta para a raiz dele.
2. No repositório, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`, depois salve.
5. Aguarde o GitHub Pages publicar. O endereço será exibido nessa mesma página de configurações.

O `index.html` já está na raiz, então a publicação pela raiz é compatível com a estrutura deste projeto. O repositório e o site publicado terão links diferentes; inclua ambos no diário de bordo.
